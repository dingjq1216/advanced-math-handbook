# 进阶数学手册

面向 **信号处理 · 控制 · 机器学习 · 泛化理论** 的数学补充手册。

**全书现状**：46 章（37 正文 + 附录 A–I）全部完稿 ｜ 约 156.5 万字 ｜ 29,794 处公式 ｜ 791 张表格 ｜ 238 张程序化 ASCII 图。

正文只讲四件事：**核心概念 → 关键方法 → 重要公式 → 典型应用**。
程序与数值工具收在第六卷及附录 I 中速查，不占正文主线。

## 一、怎么打开

**双击 `index.html`** 即可。无需安装、无需联网、无需本地服务器。

打开后你会看到：

- **左侧**：全书总目录（7 卷 37 章 + 9 个附录），已完稿的章节可点击，未完稿的标记「待写」

## 四、怎么写新章节

### 1）新建或编辑 Markdown

在 `chapters/` 下新建 `ch03.md`，**从二级标题 `##` 开始写**（一级标题由阅读器自动生成）：

```markdown
# 第 3 章　测度与勒贝格积分      ← 这一行会被忽略，标题由目录数据提供

## 3.1 测度与 σ 代数

行内公式用 $E = mc^2$，独立公式用：

$$
\int_\Omega f\,\mathrm{d}\mu = \sup_{s\le f}\int_\Omega s\,\mathrm{d}\mu
$$
```

### 2）登记到目录

文件名与章节 id 一致（`ch03.md` ↔ `ch03`）时**无需任何登记**，`build.py` 会自动找到。
若文件名不同，才需要在 `build.py` 的 `TOC` 里补上 `"src"` 字段：

```python
{"id": "ch03", "no": "3", "title": "测度与勒贝格积分", "src": "my_measure_notes.md"},
```

### 3）构建

```bash
python build.py
```

看到 `[OK] 已构建 N 章` 即完成，刷新 `index.html` 即可阅读。

### 画 ASCII 图

中文在等宽字体中占 2 格、拉丁字符占 1 格，手写框图极易错位。
请把图形定义写进 `gen_figs.py`，用程序保证对齐 —— 打开该文件，
把顶部的 `MODE` 变量设为 `"apply"` 后运行即可生成并写回 md：

```bash
python gen_figs.py        # MODE = "check" 时只做同步校验
```

> **⚠ 图内禁用这几类字符**：`⟶ ⟺ ⟹ ⇔ ⇒ ∀ ∈ ∋ ⟂ ⇀ ℝ ℂ ℕ ℤ`。
> 它们的实际宽度既不是 1 格也不是 2 格（1.3～1.8 格），会把整行撑歪。
> 替代写法：`⇒ ⟶` → `→`，`⟨⟩` → `〈〉`，`∈` → 「属于」，`∀` → 「对一切」，
> 下标一律写 `_n` 而不用 `ₙ`。`python gen_figs.py` 会自动扫描并报出违规字符。
>
> 另外，中文实际只占西文的 1.84 倍宽（不是 2 倍），所以图内每个非 ASCII 字符
> 都会由 `assets/app.js` 的 `alignAsciiGrids()` 在渲染时包进固定宽度的盒子锁死。
> **改完图建议实测一下对齐**（终端里看不出歪，只有像素测量能发现）：
>
> ```bash
> node C:\temp\wbverify\measure.mjs "#ch06"
> # 判据：spread ≤ 0.07 通过；> 0.15 说明还有宽度不整的字符
> ```

## 五、排版约定

- **公式**：行内 `$...$`，独立 `$$...$$`，也可用 `\(...\)` 与 `\[...\]`。
  **块公式一律三行写法（`$$` 独占行）**——本项目管线对同行 `$$公式$$` 也能渲染，
  但 Typora 等外部编辑器不认，从源头统一可保证任何查看器都正常；
  另注意 Typora 的**行内公式默认关闭**，需在「偏好设置 → Markdown → 内联公式」勾选后重启。
- **提示框内的公式**：可以直接写。`$$` 要**单独占行**，且每行都要带 `> ` 前缀：
  ```markdown
  > **定理 3.1**　设 $f$ 可积，则
  > $$
  > \int f = 0
  > $$
  ```
  构建脚本会自动剥掉抽出的公式里的 `> ` 前缀（否则会在公式前多渲染一个 `>`）。
- **定理条件**：一律用 `**粗体**` 显式写出（如 **若** … **则** …）
- **符号**：全书统一，见第 0.5 节「符号与约定」
- **引用**：跨章引用写作「第 X 章」，工具接口用青色的「接口」提示框
