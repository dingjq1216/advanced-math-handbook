# 第 0 章　导论：数学地图与学习路线

## 0.1 这本手册要解决什么问题

如果你能用微积分求导、会算矩阵乘法、记得正态分布的密度函数，那么你已经具备了读这本手册的**全部前置条件**。真正的问题从来不是"会不会算"，而是下面这三件事：

1. **看不懂符号背后的意图**。论文里写 $\arg\min_{f\in\mathcal{H}} \Vert f\Vert_{\mathcal{H}}^2 + \sum_i \ell(y_i, f(x_i))$，每个符号你都认识，但为什么是这个形式、为什么必须有 $\Vert f\Vert_{\mathcal{H}}^2$ 这一项、$\mathcal{H}$ 为什么是希尔伯特空间——这些才是门槛。
2. **不知道手上这个积分该不该去算**。$\int_{-\infty}^{\infty}\frac{\sin x}{x}\,\mathrm{d}x = \pi$ 可以算，$\int e^{-x^2}\mathrm{d}x$ 算不出初等原函数却处处出现。判断"能不能算、该怎么算"是工程与科研中最实际的数学能力。
3. **知识点是散的**。学过留数，但看到 H∞ 范数计算时不会用；学过 Lyapunov 函数，但没意识到它和凸优化、和 ISS、和 RL 的稳定性证明是同一件事。

本手册面向的读者画像很具体：**做信号处理、做控制、做机器学习与泛化理论的人**。这三类人的数学需求有大量重叠，但市面上的教材通常是按纯数学的学科划分组织的。本手册反过来——**按问题的依赖顺序组织**，让每一章都是下一章的地基。

> **要点**　正文只讲四件事：**概念、方法、公式、应用**。程序实现与数值工具全部收在第六卷与附录 I 中速查，不占正文主线。这不是轻视计算，而是把计算的位置放对——**计算是验证想法的工具，不是理解想法的方式**。

**读懂这张图的关键**在于 L2 那一层。很多人的知识断层正好卡在这里:

- 学信号的人会算傅里叶变换，但不知道 $\int_{-\infty}^{\infty}\frac{e^{i\omega t}}{\omega - \omega_0}\,\mathrm{d}\omega$ 这类积分必须靠**围道绕极点**来处理（第 5 章）；

## 0.3 三条主线的数学骨架

### 0.3.1 信号线：从"分解"到"表示"

信号处理的核心问题只有一句话：**把一个复杂的对象拆成一组简单对象的叠加，然后只保留需要的部分**。

这套思想在不同层级上给出了完全不同的数学工具：

| 层级 | 简单对象 | 数学结构 | 章节 |
|---|---|---|---|
| 周期信号 | 复指数 $e^{in\omega_0 t}$ | 正交基、傅里叶级数 | 12 |
| 能量信号 | $e^{i\omega t}$（连续谱） | 傅里叶变换、$L^2(\mathbb{R})$ | 12 |
| 系统响应 | $e^{st}$（复频率） | 拉普拉斯变换、极点零点 | 13 |
| 离散序列 | $z^n$ | Z 变换、差分方程 | 13 |
| 时频局部化 | 窗函数 / 小波 | 短时傅里叶、滤波器组 | 12 |
| 冗余表示 | 框架原子 | 框架理论、压缩感知 | 15 |

**贯穿全线的三个公式**：

卷积定理（第 12 章）

$$
\mathcal{F}\{x * h\} = \mathcal{F}\{x\}\cdot\mathcal{F}\{h\}
$$

帕塞瓦尔恒等式（第 12 章）

$$
\int_{-\infty}^{\infty} x(t)\overline{y(t)}\,\mathrm{d}t = \frac{1}{2\pi}\int_{-\infty}^{\infty} X(\omega)\overline{Y(\omega)}\,\mathrm{d}\omega
$$

采样定理（第 12 章）

$$
x(t)=\sum_{n\in\mathbb{Z}} x(nT)\,\operatorname{sinc}\!\left(\frac{t-nT}{T}\right),\qquad \omega_s > 2\omega_{\max}
$$

注意这三条的共同点：**它们都是"内积在变换下保持不变"的不同表述**。这解释了为什么傅里叶分析如此强大——它找到了一个让 LTI 系统对角化的基。

### 0.3.2 控制线：从"稳定性"到"性能"

控制的核心问题同样只有一句话：**给定一个可能不精确的模型，设计一个保证闭环行为满足要求的输入**。

三个层次的数学：

1. **能不能稳**——存在性层面。Lyapunov 直接法、LaSalle 不变集原理、ISS（第 18 章）。
2. **能不能好**——最优性层面。LQR、Pontryagin 极大值原理、HJB 方程、MPC（第 19 章）。
3. **模型错了还稳不稳**——鲁棒性层面。小增益定理、$\mu$ 分析、H∞、LMI（第 20 章）。

```
          模型精确 ←──────────────────────────→ 模型有不确定性

      ┌──────────────────────────┐                ┌──────────────────────────┐
      │ LQR / LQG                │                │ H∞ / μ / 小增益          │
      │ MPC                      │  ←── 折中 ──→  │ 鲁棒 MPC                 │
      │ 极点配置                 │                │ LMI 综合                 │
      └──────────────────────────┘                └──────────────────────────┘

                    ↑                                            ↑
               最优性理论                                  鲁棒性理论
             (变分法 / HJB)                         (算子范数 / 频域不等式)
```

**贯穿全线的三个公式**：

Lyapunov 方程及其积分解（第 14、18 章）

$$
A^{\mathsf T}P + PA = -Q \quad\Longleftrightarrow\quad P=\int_0^{\infty} e^{A^{\mathsf T}t}\,Q\,e^{At}\,\mathrm{d}t
$$

（注意右边是一个**收敛的反常积分**，收敛性完全由 $A$ 的特征值实部决定——第 2 章的反常积分判据在这里第一次派上大用场。）

代数 Riccati 方程（第 17、19、20 章）

$$
A^{\mathsf T}P + PA - PBR^{-1}B^{\mathsf T}P + Q = 0
$$

H∞ 范数与鲁棒稳定性（第 20 章）

$$
\Vert G\Vert_{\infty} = \sup_{\omega\in\mathbb{R}} \bar\sigma\big(G(i\omega)\big),\qquad
\Vert G\Vert_\infty < \frac{1}{\Vert\Delta\Vert_\infty}\ \Rightarrow\ \text{闭环稳定}
$$

### 0.3.3 学习线：从"拟合"到"泛化"

学习的核心问题也只有一句话：**在有限样本上表现得好的模型，凭什么在未见数据上也表现得好**。

这条线的数学重心与前面两条不同：它更依赖**概率与高维现象**。

| 问题 | 数学工具 | 章节 |
|---|---|---|
| 参数怎么估 | 极大似然、贝叶斯、最小二乘 | 10 |
| 优化能不能收敛 | 凸性、梯度下降、SGD 分析 | 25、26 |
| 为什么宽网络好训 | NTK、lazy training | 27 |
| 为什么能泛化 | 复杂度、稳定性、PAC-Bayes | 8、28、35 |
| 为什么测试误差会二次下降 | 双下降、插值学习 | 26、28 |
| 怎么生成新样本 | 扩散过程、分数匹配、SDE | 29 |

**贯穿全线的三个公式**：

经验风险最小化与泛化间隙（第 28 章）

$$
\mathcal{R}(f) \le \widehat{\mathcal{R}}_n(f) + \underbrace{\mathfrak{R}_n(\mathcal{F})}_{\text{复杂度}} + \underbrace{\sqrt{\frac{\log(1/\delta)}{2n}}}_{\text{集中}}
$$

（第二项来自第 8 章的集中不等式，第 35 章专门讨论它的估计方法。）

PAC-Bayes 界（第 28 章）

$$
\mathbb{E}\big[\mathcal{R}(f)\big] \le \widehat{\mathbb{E}}\big[\mathcal{R}(f)\big] + \sqrt{\frac{\mathrm{KL}(Q\Vert P) + \log\frac{2\sqrt{n}}{\delta}}{2n}}
$$

（注意 $\mathrm{KL}$ 项——这是第 11 章信息论与第 28 章泛化理论的接口。）

神经正切核（第 27 章）

$$
\Theta(x,x') = \Big\langle \nabla_\theta f(x;\theta),\ \nabla_\theta f(x';\theta)\Big\rangle
$$

（这是一个核函数——第 6 章 RKHS 与 Mercer 定理的直接应用。）

## 0.5 全书符号与约定

一本手册最大的隐性成本是**记号不一致**。以下约定全书强制统一，遇到特例会在当处显式说明。

### 集合与数域

| 记号 | 含义 |
|---|---|
| $\mathbb{N},\mathbb{Z},\mathbb{Q},\mathbb{R},\mathbb{C}$ | 自然数、整数、有理数、实数、复数集 |
| $\mathbb{R}^n,\ \mathbb{R}^{m\times n}$ | $n$ 维实向量空间、$m\times n$ 实矩阵空间 |
| $\mathbb{R}_+$ | 非负实数 $[0,\infty)$ |
| $\overline{z}$ | 复数 $z$ 的共轭；$\operatorname{Re}z,\operatorname{Im}z$ 为实部与虚部 |
| $\operatorname{sgn}(x)$ | 符号函数，$\operatorname{sgn}(0)=0$ |

### 向量、矩阵与范数

| 记号 | 含义 |
|---|---|
| $x,\ y$ | 列向量（默认）；$x_i$ 为其分量 |
| $A,\ B$ | 矩阵；$A_{ij}$ 或 $[A]_{ij}$ 为元素 |
| $A^{\mathsf T},\ A^{*},\ A^{\mathsf H}$ | 转置、共轭、共轭转置（$A^{\mathsf H}=\overline{A}^{\mathsf T}$） |
| $A^{-1},\ A^{+}$ | 逆、Moore–Penrose 广义逆 |
| $\operatorname{tr}A,\ \det A,\ \operatorname{rank}A$ | 迹、行列式、秩 |
| $\lambda_i(A),\ \sigma_i(A)$ | 特征值、奇异值（按模/值降序） |
| $\bar\sigma(A),\ \underline{\sigma}(A)$ | 最大、最小奇异值 |
| $\Vert x\Vert_p$ | $\ell^p$ 范数，$\Vert x\Vert_p=(\sum_i\vert x_i\vert^p)^{1/p}$ |
| $\Vert A\Vert_2,\ \Vert A\Vert_F$ | 谱范数（$=\bar\sigma$）、Frobenius 范数 |
| $\langle x,y\rangle$ | 内积，实空间为 $x^{\mathsf T}y$，复空间为 $x^{\mathsf H}y$ |
| $x\perp y$ | 正交 |
| $\mathcal{R}(A),\ \mathcal{N}(A)$ | 值域（列空间）、零空间 |
| $A\succ 0\ (\succeq 0)$ | 对称矩阵正定（半正定） |
| $\operatorname{diag}(d_1,\dots,d_n)$ | 对角矩阵 |

| 记号 | 含义 |
|---|---|
| $\partial f/\partial x_i,\ \nabla f,\ \nabla^2 f$ | 偏导、梯度、海森矩阵 |
| $Df,\ J_f$ | 雅可比矩阵 |

### 变换

| 记号 | 含义 | 定义式 |
|---|---|---|
| $\mathcal{F}\{x\}=X(\omega)$ | 傅里叶变换 | $\int_{\mathbb{R}}x(t)e^{-i\omega t}\mathrm{d}t$ |
| $\mathcal{F}^{-1}\{X\}=x(t)$ | 逆变换 | $\frac{1}{2\pi}\int_{\mathbb{R}}X(\omega)e^{i\omega t}\mathrm{d}\omega$ |
| $\mathcal{L}\{x\}=X(s)$ | （单边）拉普拉斯变换 | $\int_{0^-}^{\infty}x(t)e^{-st}\mathrm{d}t$ |
| $\mathcal{Z}\{x\}=X(z)$ | Z 变换 | $\sum_{n=0}^{\infty}x[n]z^{-n}$ |
| $\hat{x}(\xi)$ | 傅里叶变换的另一种记号 | $\int x(t)e^{-2\pi i\xi t}\mathrm{d}t$ |
| $(x*h)(t)$ | 卷积 | $\int_{\mathbb{R}}x(\tau)h(t-\tau)\mathrm{d}\tau$ |
| $x[n]*h[n]$ | 离散卷积 | $\sum_k x[k]h[n-k]$ |

> **警告**　傅里叶变换有**两套互不相容的惯例**：$\frac{1}{2\pi}$ 放在逆变换（本书默认，信号与系统教材主流）还是对称地各放 $\frac{1}{\sqrt{2\pi}}$（数学教材主流）。$\hat{x}(\xi)$ 记号则把 $2\pi$ 全部吸收进指数。跨文献阅读时**第一件事是确认惯例**，否则 Parseval 常数会全线错位。

## 0.8 阅读方法论：公式三问与定理四查

最后给出两个具体可执行的阅读习惯。它们比多记十条规定更能提高长期效率。

### 公式三问

看到一个陌生公式，依次问三个问题：

**第一问：条件是什么？** 加粗写在结论前面的限定词，往往决定了这个公式**在你手上的问题里能不能用**。例如 $\int_0^\infty \frac{\sin x}{x}\mathrm{d}x = \frac{\pi}{2}$ 是对的，但 $\int_0^\infty \left\vert\frac{\sin x}{x}\right\vert\mathrm{d}x = \infty$——把"条件收敛"当成"绝对收敛"用，是频域判据出错的最常见原因。

**第二问：结构在说什么？** 把公式按"输入 → 变换 → 输出"三段解读。例如 Lyapunov 方程 $A^{\mathsf T}P+PA=-Q$：输入是系统矩阵 $A$ 与代价 $Q$，输出是二次型的"度量"$P$，而 $P$ 同时承担了"稳定性证书"与"能量函数"两个角色。

**第三问：量纲与极限对不对？** 令参数取极端值（$\omega\to 0$、$n\to\infty$、$T\to 0$），看公式是否退化到已知结论。这是检验自己是否真正理解公式的最快方法。

### 定理四查

用一条定理之前，逐条核查四件事：

1. **定义域是否匹配**：定理要求 $f$ 在 $[a,b]$ 上连续，而你的 $f$ 在某点无界——先处理奇点，再谈结论。
2. **积分与极限能否交换**：$\lim\int = \int\lim$ 需要一致收敛或控制收敛条件（第 2、3 章）。这是工程论文中**最高频的隐性错误**。
3. **范数是什么范数**：$\Vert f\Vert$ 在没有说明时可能是 $L^2$、$\ell^2$、上确界范数或算子范数，结论完全不同。
4. **是否要求可逆 / 正定 / 有界**：Riccati 方程要求 $(A,B)$ 可稳、$(A,Q^{1/2})$ 可检测；小增益定理要求 $\Vert\Delta\Vert_\infty \Vert M\Vert_\infty < 1$。条件不满足时"定理失效"不等于"结论不真"，但要重新论证。

> **接口　→ 附录 E**　全书所有主要定理的成立条件汇编成清单，可作为推导时的查核表。
